# メール返信作成

渡された「元メールの内容」(+ 返信で伝えたい要点があればそれも)から、そのまま送れる返信メールの下書きを作成する。

## 出力フォーマット

```
件名: Re: (元メールの件名を踏まえて書く)

(宛名)

(本文)

(署名は「[署名]」のプレースホルダーのままにする)
```

## ルール
- 元メールに書かれていない事実や約束を作り上げない。回答内容が入力から読み取れない場合は「(ここに回答内容を記入)」というプレースホルダーにする
- 丁寧だが簡潔なビジネスメールの文体にする
- 絵文字や過度な前置きは使わない
