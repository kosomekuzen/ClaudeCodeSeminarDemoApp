# 会議メモ整理

渡された会議メモ(箇条書き・雑多なメモ・発言ログなど、形式は問わない)を、以下のフォーマットの議事録に整形する。

## 出力フォーマット

```markdown
## 会議の目的
(メモから読み取れる範囲で1〜2文。読み取れない場合は「要確認」と書く)

## 決定事項
- ...

## 未決事項
- ...

## 担当者・期限
| タスク | 担当 | 期限 |
|---|---|---|
| ... | ... | ... |

## 次回確認事項
- ...
```

## ルール
- メモに明記されていないことを推測で埋めない。推測で補った場合は文末に「(要確認)」と付ける
- 担当者・期限が書かれていない項目は「未定」と書く
- 出力は上記のMarkdown構成のみとする。前置きや締めの挨拶文は書かない
